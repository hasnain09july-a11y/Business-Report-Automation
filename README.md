# Business Report Automation

A Python project that reads sales data from a CSV file, analyzes business performance, and automatically generates a sales report.

## Features

- Reads sales data from a CSV file.
- Calculates total revenue and units sold.
- Counts total orders.
- Calculates average order value.
- Identifies the product with the highest revenue.
- Generates and saves a report as a text file.

## Technologies Used

- Python
- CSV module
- Collections module
- Datetime module

## How to Run

1. Make sure Python is installed.
2. Keep `business_report.py` and `sales_data.csv` in the same folder.
3. Open the terminal in that folder.
4. Run:

   `python business_report.py`

5. The program generates `business_report.txt`.

## Project Files

- `business_report.py` — Main program.
- `sales_data.csv` — Sample sales data.
- `README.md` — Project documentation.
- `.gitignore` — Files Git should ignore.

## Note

This is a learning and demonstration project using sample sales data. It is not a production financial reporting system.
